# Nommage

Un nom est lu bien plus souvent qu'il n'est écrit. Optimisez pour le lecteur
qui arrive dans six mois sans contexte.

- Dites ce qu'une chose *est*, pas quel type elle porte : `deadline`, pas
  `date_field`.
- Préférez le mot du domaine au mot générique. Si le métier dit « appel
  d'offres », le code dit `tender`, pas `opportunity`.
- Les booléens se lisent comme des affirmations : `is_expired`, `has_quorum`.
- Un nom de fonction est un groupe verbal ; un nom de classe, un groupe
  nominal.
- N'abrégez que ce que le domaine abrège déjà. `vat` passe ; `amt` non.
- Un nom qui a besoin d'un commentaire pour être compris est le mauvais nom.
