# Principes fondateurs

1. **Le code est un bien commun.** Tout changement doit être lisible et
   transmissible.
2. **La vérité métier avant l'élégance technique.** Documentez le *pourquoi*
   avant le *comment*.
3. **La dette technique est un contrat.** Suivie, assumée, planifiée.
4. **L'intégration continue est la loi.** Les tests et les contrôles de sûreté
   protègent l'ensemble et ne se négocient pas.
5. **Les migrations sont des cérémonies.** Les remaniements sont planifiés et
   automatisés.
6. **La cohérence vaut mieux que la nouveauté.** Un style partagé stable plutôt
   qu'une invention localement brillante.
7. **Le design est une source de vérité.** L'implémentation suit les jetons et
   les intentions du design, pas l'inverse.
8. **Les interfaces sont des traités.** Les interfaces de programmation et les
   contrats sont versionnés et stables.
9. **La mesure sert à apprendre.** Les journaux et les métriques existent pour
   comprendre un changement, pas pour décorer un tableau de bord.
10. **Pas de code sans raison.** Besoin métier, modèle, architecture, livraison.
