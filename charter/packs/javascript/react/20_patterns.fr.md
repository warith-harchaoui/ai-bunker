# Motifs React

- Les composants sont des fonctions. Pas de classes dans du code nouveau.
- L'état vit aussi haut qu'il le faut, et pas plus haut.
- Un effet se synchronise avec quelque chose d'extérieur. S'il ne fait que
  dériver une valeur, ce ne doit pas être un effet.
- Les clés sont des identités stables, jamais des indices de tableau.
