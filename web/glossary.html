    Glossary

    Every acronym,
    defined once.

    A reader who does not know what the Agent Payments Protocol is cannot evaluate a claim about it. These are the terms this project uses, in the sense it uses them.

    A2A

    Agent2Agent

    An open protocol for agents to talk to each other: discovery through an agent card, then tasks and messages over HTTP, the HyperText Transfer Protocol of the web. ai-bunker publishes a card and screens inbound messages, because a message another agent wrote is text crossing a trust boundary.

    A2UI

    Agent-to-User Interface

    An agent describes an interface and a host renders it, instead of the agent returning prose. Useful, and a new attack surface: the description is agent-generated and the host executes it.

    AP2

    Agent Payments Protocol

    How an agent proves a human authorised a payment. The user approves on a Trusted Surface, which the protocol defines as explicitly non-agentic, and the agent carries the signed result — a mandate.

    UCP

    Universal Commerce Protocol

    The Checkout Object standard used alongside an AP2 mandate. The mandate says what was authorised, the checkout object says what is being charged, and somebody has to compare them.

    MCP

    Model Context Protocol

    How a model reaches tools and data sources. ai-bunker exposes the charter over MCP, and only the charter.

    Agent Skills

    An open format for packaging knowledge an agent loads on demand: a folder with a SKILL.md, read natively by Claude Code, OpenCode, Cursor, Goose and others. ai-bunker publishes its charter in this format.

    JWS / JWT

    JSON Web Signature / JSON Web Token — JSON being JavaScript Object Notation

    A signed, compact token in three dot-separated parts — header, payload, signature — encoded so it survives inside a URL, a uniform resource locator. AP2 mandates arrive as these.

    JWKS

    JSON Web Key Set

    The public keys a signature is checked against. ai-bunker reads one from a file by default, so verifying a payment needs no network.

    OTLP / OpenTelemetry

    OpenTelemetry Protocol

    The standard for shipping traces to a collector. ai-bunker exports its decision log as spans, because that log is already a record of an agent's trajectory.

    KV cache

    key–value cache

    What a model keeps about the tokens already in a conversation. It grows with context and is read on every generated token, which is why context costs throughput and not only memory.

    MoE

    Mixture of Experts

    A model where each token only activates a fraction of the weights. An 80B MoE with 3B active streams less memory per token than a dense 24B, which is why the best open coder is also the fastest to serve.

    ReDoS

    Regular expression Denial of Service

    A pattern that takes exponential time on crafted input. The rule loader rejects nested unbounded quantifiers before running them, because a timing probe cannot catch what never terminates.

    Session floor

    The part of a context window paid on every single request — system prompt, tool schemas, charter, index — and which compaction cannot reduce. What is left is the only room a conversation has.

    Slopsquatting

    Registering a package name a model is likely to invent, so an agent installs it. No registry lookup helps: the malicious package is registered precisely so the lookup passes.

    Gherkin

    A plain-language format for behaviour specifications: Given / When / Then. ai-bunker renders its rule set as Gherkin so the person who approves it does not have to read regular expressions.
